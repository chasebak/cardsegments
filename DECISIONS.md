# Decisions

Dated design decisions, one per upgrade, written as "decided X because
measurement Y; alternative Z lost by N". Nulls and reversals go in too.
The entries below are generated from `results/ladder_frozen.json` by
`python -m cardsegments.ladder_report build` and from
`reports/results_bundle.json` by `python -m cardsegments.synth_findings
build`, and the Buy List Explorer entries from `results/buylist_grid.json`
by `python -m cardsegments.viz build`, so every number in them is copied from a tested script's output;
`tests/test_readme_drift.py` fails if they drift. Everything here is
measured on SYNTHETIC data, never on the private cohort.

## Model ladders and the buy list (synthetic)

<!-- ladder-decisions:begin (generated by python -m cardsegments.ladder_report build; do not edit) -->
### 2026-11-04 — Leakage and planted-truth checks before any ladder number
Decided to run a row-level shuffled-label control on the same grouped folds and an oracle row before reading the ladders, because the ≥ 5-sales label sits close to trailing sales; measurement: every non-constant rung's shuffled fold-mean AUC fell inside [0.466, 0.534] at both signals (band check passes: yes) and 0 rung(s) beat the oracle. Alternative: a group-level shuffle (whole sets swap labels) — rejected because unequal set sizes make it ill-defined; the plan's row-level shuffle with grouped folds kept was used.

### 2026-11-04 — Constant baselines left out of the shuffle band
Decided to exclude majority and mean from the band because a per-fold constant scores fold AUC exactly 0.5000 while its pooled out-of-fold AUC is 0.4902 at signal 0.9 (biased by fold base rates); alternative (include them) would test the splitter, not leakage.

### 2026-11-04 — Shuffle band and R² gate from trial seeds, written down first
Decided band = 0.5 ± 3 × single-fold sd (0.0113, from 120 trial cells) and R² gate = 0.014 (trial velocity-OLS fold sd, rounded up), registered before the frozen run, because a band set from the frozen seeds would be fitted to the result it judges; alternative (fixed round numbers) had no measurement behind it.

### 2026-11-04 — The R² gate on its own scale
Decided the count ladder's gate is 0.014 R² (the trial velocity-OLS fold sd), not the +0.01 AUC bar, because R² and AUC have different fold noise; measurement: reusing +0.01 would flip 0 PASS/FAIL verdict(s) across the two signals, so on this run the choice is about using the right noise scale, not about the outcome.

### 2026-11-04 — Reuse `gbc`; no new HGB rung
Decided to keep the existing deterministic GradientBoostingClassifier (random_state 42, defaults) as the boosting rung because at signal 0.9 its fold-mean AUC is 0.9746 vs 0.9663 for the full logistic (+0.0084), under the +0.01 bar, at 64.3 s of fitting for 50 cells; alternative (HistGradientBoosting + threadpoolctl thread pinning) was not built: it adds a rung class and a thread setting for a family already on the ladder.

### 2026-11-04 — `primary_logistic` relabelled as L2, C = 1
Decided to label the old primary model honestly as 'full logistic, L2 C=1' and add a truly unpenalized rung (C = inf) beside it, because scikit-learn's default is L2 with C = 1; measurement: the two differ by +0.0000 fold-mean AUC at signal 0.9, so the label was wrong but the number barely moves. The bundle key `primary_logistic` is kept so the committed aggregates bundle still renders; alternative (rename the key) would break that bundle until a gated rerun.

### 2026-11-04 — Velocity, not 'buy everything', as the comparator
Decided the headline compares against the velocity logistic because 'buy everything' parks 76.7% of cards at signal 0.9 vs 31.1% for velocity, a straw man by +45.55 pp; alternative kept only as a context row.

### 2026-11-04 — Illustrative preset values; show the null and the planted case
Decided on round illustrative values (n = 12,000, 150 groups, planted base rate 0.23; realized 0.229 and 0.233) and to show signal 0 beside 0.9, because the private cohort's n and base rate are licensed-feed aggregates and a demo with only the planted case would hide that the model's lead depends on it; measurement: ΔAUC +0.0966 [+0.0787, +0.1149] at signal 0.9 vs -0.0001 [-0.0004, +0.0002] at signal 0. Alternative (size the preset to the private cohort) rejected: it would publish those licensed-feed aggregates.

### 2026-11-05 — The GLM-oracle deviance bound holds at signal 0 only
Decided to keep the 'Poisson GLM deviance within 0.03 of the oracle' check at signal 0 only, because measurement: the gap is 0.0006 at signal 0 (the planted log-rate is linear in trailing sales) but 0.3366 at signal 0.9, 11.2× the bound, since the GLM is linear in the features and cannot represent the planted segment offsets. Alternative (bound both signals) would fail at 0.9 by 0.3066 and test the GLM's functional form, not leakage; the 0.9 gap is printed in results/LADDER.md instead.

### 2026-11-05 — The leakage band kept as registered; its detection limit measured
Decided not to retune the pre-registered band (half-width 0.034) after seeing that it is wide, because a band changed after the frozen run would be fitted to the result it judges; measurement: honest rungs' shuffled fold means span 0.4995 to 0.5040, and a moderate-leak control (label + noise as a feature, n = 3,000) passes at shuffled fold-mean AUC 0.5327 and is caught at 0.5428, so the band misses leaks up to about 0.033 above 0.5. Alternative (a band from the sd of the fold MEAN across trial seeds) is the rule for any future registration.

## Findings report, synthetic-only v2

<!-- findings-decisions:begin (generated by python -m cardsegments.synth_findings build; do not edit) -->
### 2026-11-04 — Findings regenerated on synthetic data only
Decided to replace the licensed-feed findings, bundle and figures with a synthetic v2 (the real-data text moved to a local private folder outside the repo) because the feed terms are unread and any tracked aggregate is published by a push; measurement: the same method on the illustrative preset still tells the honest-null story, the nested gate FAILS (null) at signal 0 (mean dAUC -4.29e-05, CI [-0.000164, 0.000105], ships=False) and PASSES at signal 0.9 (mean dAUC 0.0265, CI [0.0224, 0.0308], ships=True). Alternative (keep the real bundle with a 'private' label) rejected: a label does not stop a push; alternative (wait for the terms) would hold the whole repo for one report.

### 2026-11-04 — Signal 0 is the primary supervised case
Decided to print cluster_signal 0 first and 0.9 second because the null is the case the method must be honest about; measurement: base rate 0.229 vs 0.233, so the two cases differ in the planted segment effect, not in size. Alternative (show only the planted case) would hide that the gate's verdict depends on it.

### 2026-11-04 — No synthetic price trends
Decided to leave the per-segment trend tables out of the synthetic report because the generator has no price history; alternative (the demo's random changes with bootstrap CIs) lost because it prints numbers that read like market findings and measure nothing.

### 2026-11-04 — Gap statistic stays the structure arbiter
Decided to keep the gap statistic and bootstrap stability as the arbiters and silhouette/BIC as descriptive because on the synthetic nulls BIC picks full k=1 (matched Gaussian) and diag k=2 (column-shuffled) while the gap statistic picks k=1 and k=1; alternative (BIC as arbiter) would call structure in a null whenever it picks k > 1. The cost, measured on the planted V1 data: the gap statistic picks k=1 against a planted k=4 at separation 2 (prediction 1: refuted), so it is conservative; the rule is kept and the miss ships as printed rather than retuning the arbiter after seeing it.

### 2026-11-04 — Real-cohort identifiers checked locally, not in a public test
Decided that the check 'no tracked file carries the private cohort's n or base rate' runs in the local deny-list check (outside the repo, before every push) because a public test would have to contain those values; alternative (a public test with hashed values) rejected: a short number's hash is easy to reverse by trying every value.

## Buy List Explorer page (synthetic)

<!-- explorer-decisions:begin (generated by python -m cardsegments.viz build; do not edit) -->
### 2026-11-04 — Buy-list grid recomputed from two rungs, checked against the frozen run
Decided to recompute only the full-logistic and velocity rungs (same preset, folds and 10 CV seeds) for the 49-point grid because the recompute reproduces the frozen ladder's t* = 2/3 TP/FP/FN/TN for both lists and its parked-delta CI at both signals (exact match: yes; the page build stops if it does not); measurement: 2.5 s for the recompute vs 256.4 s of model fitting in the frozen run's real-label ladders alone. Alternative (re-run the frozen ladder with a grid key) lost by at least 253.9 s and would rewrite a file pinned to its predictions.

### 2026-11-04 — Tiles and regret use the exact t* cell, not the nearest slider stop
Decided that every t* number comes from the exact t* cell because 2/3 and 3/4 are not grid points; measurement: at signal 0.9 and t* = 2/3 the full logistic's list flags 2,180 cards with parked rate 11.83%, while the nearest stop (t = 0.66) flags 2,210 with 11.95%. Alternative (snap t* to the slider) misstates the headline parked rate by +0.11 pp.

### 2026-11-04 — Regret shown, no 'best threshold' button
Decided to show threshold regret (cost at the exact t* minus the hindsight-best grid cost) instead of letting the page pick the cheapest threshold, because the cheapest threshold needs the test labels; measurement: the largest regret over 3 settings × 2 lists × 2 signals is 3.95% of the cost at t* (velocity logistic (trailing sales), signal 0.9, m 0.10 · h 0.20 → t* = 3/4). Alternative (tune t on the grid) gains at most that 3.95% and reads outcomes it would not have at buy time.

### 2026-11-04 — The page opens on the planted case and toggles to the null
Decided to put the signal toggle next to the slider because the model's lead depends on the planted segment effect; measurement: the parked-delta CI lies above 0 at 3 of 3 cost settings with signal 0.9 and at 0 of 3 with signal 0. Alternative (show only the planted case) would hide the null.

### 2026-11-04 — Grid shipped as 49-entry columns
Decided to write each list's grid as one 49-entry list per count because measurement: the page data are 45,891 bytes that way vs 65,203 bytes as row objects (budget 150,000). Alternative (row objects) lost by 19,312 bytes; both fit, so the choice is about load time on a phone.

### 2026-11-05 — No n < 50 suppression on the synthetic page
Decided not to re-apply report.apply_disclosure (the n >= 50 floor) to the page's grid cells because the data are synthetic and the build refuses any source not labelled SYNTHETIC; measurement: 2 of 196 grid cells (2 signals × 2 lists × 49 thresholds) hold a buy list under 50 cards, the smallest non-empty one 7 cards (velocity logistic (trailing sales), signal 0.9, t = 0.98). Alternative (apply the floor and show '–') would blank those 2 cells at the top of the slider and protects no one on synthetic cards; it stays the rule for a real-data page, which must re-apply apply_disclosure before it is built.
