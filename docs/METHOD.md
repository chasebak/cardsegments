# Method notes and background

The README keeps only the two load-bearing citations (silhouette and the
gap statistic). Fuller background for each pipeline stage lives here.

## Feature screening (`screen.py`)

Features are grouped into blocks by average-linkage hierarchical
clustering on the distance `1 - |Spearman rho|`, cut at 0.2 (so a block is
a set of features with average absolute rank correlation >= 0.8). One
representative per block survives: the feature with the highest
non-missing coverage, ties broken by declared order. The rule is fixed ex
ante, so pruning never peeks at clustering results. VIF is computed via
`numpy.linalg.lstsq` on standardized complete cases; a ranked table of
univariate R^2 on `f_log_raw_price` measures how much each feature merely
proxies price level. The V4 transform residualizes a fixed list of
features on log raw price (per-feature OLS, fit once, applied anywhere),
keeping price itself as one standalone axis.

## Cluster-count selection (`cluster.py`)

Two method families with fixed, per-method criteria:

- k-means (n_init=10): silhouette width (Rousseeuw 1987) and the gap
  statistic (Tibshirani, Walther & Hastie 2001) with the PCA-aligned
  uniform reference box (their method b), B=50 references, the one-SE
  rule, and k=1 allowed. A gap choice of k=1 is a no-structure verdict
  and stands; the silhouette k then becomes a profiling fallback,
  reported, never hidden.
- Gaussian mixtures over {spherical, diag, full} covariances: BIC and ICL
  (BIC plus twice the posterior assignment entropy, Biernacki, Celeux &
  Govaert 2000). ICL penalizes overlapping components that BIC tolerates.

Within-method disagreements are recorded and tiebroken by bootstrap ARI;
the dataset's single chosen solution is the method/k with the higher mean
bootstrap ARI. Nothing is tuned on real-data outcomes.

## Stability (`stability.py`)

B resamples of 80% of rows without replacement, full refit per resample,
ARI of refit labels against the full-data labels on the sampled rows
(Hubert & Arabie 1985 adjusted Rand index). Hungarian matching aligns
resample clusters to full clusters; the matched labels are what era-lift
CIs use. Reported: mean, SD, min and 5th-percentile ARI, plus ARI at
k* +/- 1.

## Null controls (`nullcontrol.py`)

The identical selection pipeline runs on (a) one multivariate normal
matched to the input's mean/covariance and (b) column-shuffled data. The
fixed methodological rule the module documents: mixture criteria and the
silhouette respond to non-Gaussian marginals, not only to cluster
structure, so the gap statistic and bootstrap stability are the structure
arbiters and silhouette/BIC are read as descriptive. The synthetic
null-control table in `reports/findings.md` shows each criterion's pick on
both nulls.

## Supervised validation (`supervised.py`)

StratifiedGroupKFold (groups = set ids, stratified on the outcome), 5
folds x 10 seeds; imputation and scaling are refit inside every training
fold. The cluster value-add gate re-fits clusters inside each training
fold (k frozen at the full-data k* - a mild selection leak, disclosed),
assigns test rows with complete cluster features by the fold-fitted
model, and gives every other row an explicit `no_cluster` category, so
the nested comparison (era + velocity + cluster vs era + velocity) runs
on the full cohort. The delta-AUC CI comes from a paired group-level
bootstrap (B=1000) on pooled out-of-fold predictions; per-fold t-tests
were rejected because CV folds are not independent (the Nadeau-Bengio
correction was the considered alternative). The decision threshold comes
from the cost ratio t* = C_FP / (C_FP + C_FN) with C_FP = m + h (margin
plus holding cost of a card that sits) and C_FN = m (margin missed); the
threshold-cost curve is drawn for three (m, h) settings so no conclusion
hinges on one.

## Disclosure (`report.py`)

Aggregates only, for any bundle: any per-group cell with n < 50 is
suppressed in code, medians/IQR only, era shares as whole percents, 2-3
significant figures. findings.md and every figure are regenerated from
`reports/results_bundle.json`. The committed bundle is synthetic
(`provenance.label = "synthetic"`, written by `synth_findings.py`);
`report.render_findings` refuses to write any other bundle into the
repo's `reports/` directory (see `DECISIONS.md`, 2026-11-04 — Findings
regenerated on synthetic data only). A private licensed-data bundle
renders through the same code into a directory outside the repo.
