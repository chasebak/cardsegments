# Model ladders on the illustrative synthetic preset

Generated by `python -m cardsegments.ladder_report build` from `results/ladder_frozen.json`; do not edit by hand. Every number is SYNTHETIC: the illustrative preset (n = 12,000, 150 set groups, planted base rate 0.23, liquid = at least 5 sales), round values that are not the private cohort's.

Protocol: StratifiedGroupKFold, 5 folds × 10 CV seeds (0-9), groups = set ids; impute + scale refit inside every training fold; the same fold indices for every rung of both ladders. Fold metrics are mean ± sd (ddof = 1) over the 50 fold-seed cells; pooled metrics use per-card out-of-fold predictions averaged over seeds, with a group-bootstrap CI (B = 1000). 'Beats' = the paired CI excludes 0 AND Δ ≥ +0.01 AUC (or ≥ the R² gate 0.014). Fit seconds are wall-clock on the machine that ran the frozen run (scikit-learn 1.8.0) and vary between machines.

The Poisson GLM's shuffled R² is well below 0, not near it: with shuffled counts it fits a near-constant mean and maps it through the Poisson E[log1p N], but the shuffled counts are a mixture (over-dispersed), so that mapping is biased on the log1p scale. Below 0 is what the bound allows; only values above it would point to leakage.

Detection limit of the registered band (moderate-leak control, `results/leak_detection.json`, n = 3,000, 10 fold cells per leak): a leak scoring shuffled fold-mean AUC 0.5327 (label + N(0, 6²) noise) still passes, while the weakest leak caught scores 0.5428 (noise sd 5); the limit lies between the two, since the band catches nothing at or below 0.5327. Honest rungs' shuffled fold means span 0.4995 to 0.5040 across both signals, so the band (half-width 0.034, set from a single-fold sd) is far wider than the spread it guards. The band stays as registered; a future registration should set it from the sd of the fold MEAN across trial seeds.

> **Why this metric.** Could the ladder's numbers come from leakage instead of signal?
> *Kind of number:* Simulated control: the same folds with labels permuted at row level; a clean pipeline scores AUC near 0.5 and R^2 near or below 0.
> *What would make it lie:* A leak weaker than the band's measured detection limit would pass (the band uses a single-fold sd for a 50-cell fold mean, so it is wide); the band was written down from trial seeds before the frozen run, a planted label leak must fall outside it, and a moderate-leak control records the weakest leak it catches (tests/test_ladder.py).
