# synth/ — committed synthetic example datasets

Both datasets here are **generated by this repo's code** (seeded, fully
reproducible) and exist so a cloner can see the adapter schema filled in
without running anything. Regenerate them with:

```python
from cardsegments.synth import generate_segmented, generate_supervised, write_dataset

frame, manifest, _ = generate_segmented(
    n_rows=1200, n_clusters=4, separation=2.5, seed=0, missingness=True,
    name="example_segments")
write_dataset(frame, manifest, "synth")

frame, manifest, _ = generate_supervised(
    n_rows=1200, n_clusters=3, separation=2.5, seed=0,
    name="example_supervised")
write_dataset(frame, manifest, "synth")
```

- `example_segments.*` — planted-segment clustering data (4 clusters,
  separation 2.5, planted missingness in the gem-rate column).
- `example_supervised.*` — the supervised variant with planted outcome
  structure (cluster membership adds signal beyond trailing velocity and
  era) and ~30% missing cluster features, exercising the `no_cluster`
  path.

The model ladders (`python -m cardsegments.ladder`) do not read these files;
they draw the **illustrative preset** in memory with
`cardsegments.synth.illustrative_preset(cluster_signal)`: round, labelled
illustrative values (never the private cohort's n or base rate), the
threshold outcome mode (`y_liquid` = at least 5 sales, so both ladders share
one outcome), and the planted truth returned as `truth["p_liquid"]` and
`truth["lambda_sold"]`. Its values are listed in the assumptions table in
`docs/METHOD.md`. The new parameters' defaults leave the two files here
unchanged (`tests/test_synth.py`).

No real market data appears anywhere in this directory.
